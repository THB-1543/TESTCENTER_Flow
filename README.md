# TESTCENTER Flow – Prüfstand-Planungstool

Ein webbasiertes Planungs- und Belegungstool für Prüfstände. Entwickelt mit React 18, TypeScript, Vite und Tailwind CSS.

## Features (Phase 1)

- **Gantt-Chart Belegungsplan** – Visuelle Übersicht aller Prüfstände mit farbcodierten Buchungsblöcken, Drag-and-Drop
- **Buchungsverwaltung** – Erstellen, Bearbeiten und Löschen von Buchungen mit vollständigem Formular
- **Ressourcenmanagement** – Verwaltung von Prüfständen, Equipment und Personal
- **Kompetenzmatrix** – Übersicht der Mitarbeiterqualifikationen
- **Dark Theme** – Modernes dunkles Design
- **Datenpersistenz** – Automatisches Speichern im localStorage

## Installation & Start

```bash
npm install
npm run dev
```

Öffne [http://localhost:5173](http://localhost:5173) im Browser.
